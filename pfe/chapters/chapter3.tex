\section{Introduction}
In this chapter, we present the implementation details of our car rental management system. We will cover both the backend and frontend implementations, focusing on the technical aspects and architectural decisions that shaped our solution. The implementation follows the design specifications outlined in the previous chapters, utilizing modern technologies and best practices.

\section{Backend Implementation}
\subsection{Project Structure}
The backend of our system is built using NestJS, a progressive Node.js framework for building efficient and scalable server-side applications. The project structure follows NestJS best practices and is organized as follows:

\begin{itemize}
    \item \textbf{src/}
    \begin{itemize}
        \item \textbf{auth/} - Authentication and authorization module
        \item \textbf{vehicles/} - Vehicle management module
        \item \textbf{reservations/} - Reservation system module
        \item \textbf{offices/} - Office management module
        \item \textbf{clients/} - Client management module
        \item \textbf{agents/} - Agent management module
        \item \textbf{reviews/} - Review system module
        \item \textbf{admins/} - Admin management module
        \item \textbf{cloudinary/} - Image management module
    \end{itemize}
    
    \item \textbf{test/} - Test files and configurations
    \item \textbf{dist/} - Compiled JavaScript files
    \item Configuration files:
    \begin{itemize}
        \item \textbf{package.json} - Project dependencies and scripts
        \item \textbf{tsconfig.json} - TypeScript configuration
        \item \textbf{.env} - Environment variables
        \item \textbf{database.sql} - Database schema
    \end{itemize}
\end{itemize}

\subsection{Database Design}
The database is implemented using MySQL and follows a relational model. Key tables include:

\begin{itemize}
    \item \textbf{users} - Stores user information with role-based access
    \item \textbf{vehicles} - Contains vehicle details and specifications
    \item \textbf{reservations} - Manages booking information
    \item \textbf{offices} - Stores rental location details
    \item \textbf{reviews} - Handles customer feedback
    \item \textbf{images} - Manages vehicle and office images
    \item \textbf{payments} - Tracks payment information
\end{itemize}

Relationships between tables are maintained using foreign keys, ensuring data integrity and consistency.

The authentication system is implemented using JWT (JSON Web Tokens) and includes:

\begin{itemize}
    \item User registration and login endpoints
    \item Role-based access control
    \item Password hashing and security
    \item Token refresh mechanism
    \item Session management
\end{itemize}

The vehicle management module provides endpoints for:

\begin{itemize}
    \item CRUD operations for vehicles
    \item Vehicle status tracking
    \item Image upload and management
    \item Search and filtering
    \item Availability checking
\end{itemize}

\subsubsection{Reservation System}
The reservation system includes:

\begin{itemize}
    \item Booking creation and management
    \item Availability checking
    \item Price calculation
    \item Status updates
    \item Payment processing
\end{itemize}

\subsubsection{Office Management}
Office management features:

\begin{itemize}
    \item Location management
    \item Agent assignment
    \item Inventory tracking
    \item Performance metrics
\end{itemize}

\subsubsection{Review System}
The review system implements:

\begin{itemize}
    \item Review submission and management
    \item Rating system
    \item Moderation tools
    \item Statistics tracking
\end{itemize}

\section{Conclusion}
In this chapter, we have detailed the implementation of our car rental management system. The backend, built with NestJS, provides a robust API for all system operations, while the frontend, developed with Angular, offers an intuitive user interface. The implementation follows modern development practices and ensures scalability, maintainability, and security. The integration between frontend and backend components creates a seamless user experience across all system features.
