\section{Project Management}
\subsection{Project Presentation}
In the context of our project, we have developed an innovative car rental management system named "RentyCar." This solution consists of two distinct parts: An administrative interface and a user application.

On the administrative side, administrators can manage users, vehicles, offices, and reservations. They have complete control over the system's operations, from tracking vehicle availability to monitoring business performance.

On the user side, the application allows customers to browse available vehicles, make reservations, manage their bookings, and handle their profiles. The interface is designed to be intuitive and user-friendly, making the car rental process smooth and efficient.

By integrating features such as real-time vehicle tracking, automated reservation processing, and comprehensive user management, our system enables users to navigate the car rental process with ease while enjoying a pleasant and intuitive experience.

\subsubsection{Critique of Existing Solutions}

Car rental apps in Tunisia have problems that need fixing. These include hard-to-use designs, trouble finding specific cars, and slow booking steps.

For example, the \textbf{MS Cars app} has issues with talking to service providers, especially in faraway places. Services like car delivery or customer help are not always available in some areas, but the app works better in cities.
\begin{itemize}
    \item Talking to service providers should be easier for a better customer experience.
    \item Services in rural areas are often limited.
\end{itemize}


On the other hand, \textbf{CityGo} has a design that sometimes crashes and shows wrong details about available cars.
\begin{itemize}
    \item The user interface needs optimization to improve the booking experience.
    \item Frequent crashes and inaccurate availability information.
\end{itemize}

This system, while functional, may not scale well for larger rental operations with multiple locations.

\subsubsection{Proposed Solution and Objectives}
At RentyCar, our goal is to offer users a smooth and efficient car rental experience. From the moment customers visit the platform to when they complete a booking, we want every step to be easy, clear, and enjoyable.

The system is built to be strong and reliable. It keeps track of everything: available cars, customer reservations, agent and office details, and even user reviews. We make sure everything works well together.

These features include advanced vehicle management with detailed specifications, flexible reservation system with status tracking, comprehensive user management with role-based access, and office and agent management capabilities. The system also incorporates a review and rating system, image management for vehicles, and secure payment processing, all presented through a simple and pleasant interface with smooth navigation between different sections of the application.

Through these innovations, we hope to provide a unique and efficient online rental experience, meeting the expectations of modern consumers and promoting the growth of our platform in the car rental sector.

\subsection{Identification of Actors}
The system interacts with three main authenticated actors and one unauthenticated actor, each with specific access levels and interfaces:

\begin{itemize}
    \item \textbf{Administrators} have full access to the entire system through a dedicated admin interface. They are responsible for managing all key entities in the platform like users, cars, offices, bookings, and reviews.They also manage system-wide settings and configurations, ensuring smooth operation across all aspects of the platform. Additionally, administrators can view and moderate all user reviews and ratings to maintain a trustworthy environment.
    
    \item \textbf{Agents} are linked to a specific office at the time of registration. They are responsible for managing the vehicles and handling reservations within their assigned office. Agents interact directly with customers, handling tasks like check-ins and check-outs.
    
    \item \textbf{Clients} can browse and search for available vehicles, make reservations, and manage their bookings. Clients are also allowed to leave reviews and give ratings for the vehicles they've rented.
    
    \item \textbf{Visitors} are unauthenticated users who can explore the platform without registering they can also  browse available vehicles, view detailed specifications, read reviews and ratings, and see office locations along with contact information.
\end{itemize}

\subsubsection{Functional Requirements}

\noindent\textbf{Administrator (Admin):}
\begin{itemize}
 \item \textbf{Profile Management:} Admins can update their profiles. They can view all their personal information, and if they decide, they can delete their profile from the system.
    \item \textbf{Agents Management:} Create and manage agent accounts, update their profiles, and remove accounts when needed.
    \item \textbf{Vehicle Management:} Access and manage all vehicle listings within the system. They are able to view a complete list of all vehicles and access detailed information about each one. They also have the ability to update existing vehicle details, such as pricing or descriptions, and to remove vehicles from the system when necessary.
    \item \textbf{Reservation Management:} Administrators can see a complete list of all bookings, making it easy to understand booking activities. They can change the status of bookings, track them, or make changes when needed to keep things running well and improve customer service.
    
    \item \textbf{Office Management:} Full management of rental office locations. They can create a new office and update their information. Offices can also be removed from the system when they are no longer in operation. Additionally, administrators can assign agents to specific offices, ensuring that each location is managed by the appropriate personnel.
    
    \item \textbf{Review Management:} Manage all user reviews on the platform. They use one simple area to see every review, making it easy to check and control them. They can also delete any review if needed.
\end{itemize}
\noindent\textbf{Agents:}
\begin{itemize}
    \item \textbf{Vehicle Management:} The  system helps agents easily manage cars in their office. They can create and view all vehicle full details in their office, making sure they have all the information. Agents can also remove cars from the office's list when needed.
    
    \item \textbf{Review Management:} Agents are allowed to effectively manage reviews, they view all reviews associated with their office vehicles, gaining insight into customer feedback. They also have the authority to delete reviews for these vehicles.

\newpage
    \item \textbf{Reservation Management:} View a comprehensive list of all reservations, providing clear visibility into booking activities.to update the status of reservations, Additionally they can track and modify booking progress as needed, ensuring smooth operations and enhanced customer service for their office's vehicle reservations.
    \item \textbf{Profile Management:} Agents can update their profiles. They can see all their personal details, and if they want, they can remove their profile from the system.
\end{itemize}

\noindent\textbf{Clients:}
\begin{itemize}
    \item \textbf{Vehicle Management:} Clients can see all cars available in the system. They can also check detailed information about any car to help them choose wisely. Plus, clients can sort cars by things like make, model, or features, making it easy to find exactly what they want.
    
    \item \textbf{Profile Management:} Clients can view their own profile to review their current information, update their profile details to keep their data accurate, and change their password to enhance account security. Additionally, they have the option to delete their own profile, providing the flexibility to remove their account when desired.
    
    \item \textbf{Reservation Management:} Create new bookings to choose vehicles that match their needs. They have access to a full history of their bookings, allowing them to keep track of past and current reservations. If plans change, clients can modify upcoming bookings to update any necessary details or cancel them altogether.
    
    \item \textbf{Review Management:} Clients can manage their reviews easily through the platform. After renting a vehicle, they can submit a review to share their experience, including a star rating from 1 to 5 and written comments. If they wish to make changes, clients have the ability to edit their existing reviews or delete them entirely. This flexibility ensures that their feedback remains accurate and up to date, helping other users make informed decisions.
\end{itemize}

\noindent\textbf{Visitors:}
\begin{itemize}
    \item \textbf{Vehicle Browsing:} Visitors can freely browse the platform to explore available vehicles without needing to create an account. They can view detailed information and specifications for each vehicle, helping them understand the options before deciding to sign up or make a booking. 
\end{itemize}

\subsubsection{Non-Functional Requirements}
Non-functional requirements encompass a set of criteria intended to evaluate the operation of a system. In the continuation of our presentation, we will outline the requirements that our solution must meet:

\begin{itemize}
    \item Frontend Performance:
    \begin{itemize}
        \item Fast page load times (< 3 seconds)
        \item Smooth transitions and animations
        \item Efficient data loading and caching
        \item Responsive design across all devices
    \end{itemize}
    
    \item Security:
    \begin{itemize}
        \item JWT-based authentication and authorization
        \item Secure data transmission (HTTPS)
        \item Environment variable protection for sensitive data
        \item CORS configuration for production
        \item Protection against common web vulnerabilities
        \item Regular security updates
    \end{itemize}
    
    \item Scalability:
    \begin{itemize}
        \item NestJS modular architecture for horizontal scaling
        \item TypeORM for efficient data management
        \item Support for multiple rental locations through office management
        \item MySQL database optimization for high load
        \item Caching strategy implementation
    \end{itemize}
    
    \item Reliability:
    \begin{itemize}
        \item High availability (99.9\% uptime)
        \item TypeORM transactions for data consistency
        \item Comprehensive error handling and logging
        \item Automated database backup strategy
        \item Monitoring and alerting system
    \end{itemize}
    
    \item Maintainability:
    \begin{itemize}
        \item NestJS modular architecture
        \item TypeScript for type safety and documentation
        \item ESLint and Prettier for code quality
        \item Comprehensive test coverage with Jest
        \item API documentation
        \item Clear separation of concerns in modules
    \end{itemize}
    
    \item Integration:
    \begin{itemize}
        \item Cloudinary integration for image management
        \item RESTful API endpoints with NestJS
        \item MySQL database integration
        \item Payment gateway integration (to be added)
        \item Email notification system (to be added)
    \end{itemize}
\end{itemize}
